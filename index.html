ScanType プライバシーポリシー

最終更新日: 2026年10月7日

「ScanType」(以下「本アプリ」)は、QRコード・バーコードを読み取り、その内容を入力欄に出力するキーボードアプリです。 本ポリシーは、本アプリがどのような情報を扱うかを説明します。

1. 取得する権限とその理由

  • カメラ: QRコード・バーコードを読み取るためだけに使用します。読み取りはすべて端末内で処理され、画像や映像を保存・送信することはありません。
This app requests Camera permission solely to scan QR codes/barcodes. All processing happens on-device; no image or video is stored or transmitted.

2. インターネット通信・データ送信について

本アプリはインターネット接続の権限を持っていません。読み取ったQRコード・バーコードの内容、入力した文字、設定内容など、本アプリが扱うあらゆるデータは、外部のサーバーやクラウドサービスに送信されることはありません。すべての処理は端末内(オンデバイス)で完結します。

This app has no INTERNET permission. Nothing you scan or type is ever transmitted to any server — all processing is fully on-device.

3. キーボードとしての動作について

本アプリは入力方式(IME)として動作しますが、QRコード・バーコードのスキャン操作に関する記録以外、ユーザーが入力したキー入力内容を記録・収集することはありません。

4. アプリ内ログについて

動作確認のため、スキャン操作や権限結果などの簡易なログを端末内のみに一時的に保存する機能があります。このログは外部に送信されることはなく、アプリの設定画面からユーザー自身が内容の確認・共有・消去を行えます(共有は、ユーザーが明示的に「共有」ボタンを押した場合のみ、端末のOS標準の共有機能を通じて行われます)。

5. 第三者への提供

本アプリは広告SDK・解析SDK・第三者トラッキングを組み込んでいません。取得した情報を第三者に提供することはありません。

6. お子様の利用について

本アプリは特定の年齢層を対象としたものではなく、個人を特定する情報を収集しません。

7. ポリシーの変更

本ポリシーは、アプリの機能追加等に応じて変更される場合があります。変更後は本ページに反映します。

8. お問い合わせ

本アプリに関するお問い合わせは、Google Playのストア掲載ページに記載の連絡先までお願いします。
